# 要件定義書：Trello風タスク管理アプリ

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026-11-18 |
| 版 | 0.1（ドラフト） |
| 状態 | 確認待ち（【要確認】の項目あり） |

## 1. 目的・背景

- スクールの課題として制作する。
- 完成後は作成者本人が日常のタスク管理に実際に使う。
- Trelloのように、タスクをカードとして扱い、リスト（列）間を移動させて進捗を管理できるアプリを作る。

## 2. 利用者・利用環境

| 項目 | 内容 |
| --- | --- |
| 利用者 | 作成者本人のみ（1人） |
| 利用環境 | PCのWebブラウザ（Chrome / Edge の最新版を想定） |
| 認証 | 不要 |
| データ保存先 | ブラウザ内（localStorage）。サーバーは使わない |

## 3. 用語定義

| 用語 | 意味 |
| --- | --- |
| ボード | リストを並べて表示する作業画面 |
| リスト | カードを縦に並べる列（例：未着手 / 進行中 / 完了） |
| カード | 1つのタスク |
| ラベル | カードに付ける色付きの分類タグ |

## 4. 機能要件

優先度は、◎＝必須、○＝実用上必要、△＝将来追加する機能とする。

### 4.1 第1段階：基本機能（◎）

| ID | 機能 | 内容 |
| --- | --- | --- |
| F-01 | リスト追加 | タイトルを入力してリストを追加できる |
| F-02 | リスト編集 | リストのタイトルを変更できる |
| F-03 | リスト削除 | リストを削除できる（中のカードも削除。確認ダイアログを表示） |
| F-04 | カード追加 | リスト内にタイトルを入力してカードを追加できる |
| F-05 | カード編集 | カードのタイトルを変更できる |

| F-07 | カード移動 | ドラッグ&ドロップで、リスト内の並び替えとリスト間の移動ができる |
| F-08 | 自動保存 | 操作のたびに自動で保存し、再読み込み後も状態が復元される |

### 4.2 第2段階：実用機能（○）

## 5. 非機能要件

| 区分 | 要件 |
| --- | --- |
| 操作性 | 主要な操作（追加・編集・移動）を、画面遷移なしに1〜2操作で行える |
| 性能 | カード数100件程度でも、操作の反応が遅れない |
| データ保全 | 保存はブラウザ内のみのため、ブラウザのデータ削除で消える。第3段階のバックアップ機能（F-17）で対策する |
| 互換性 | Chrome / Edge の最新版で動作する |
| 保守性 | 機能ごとにコンポーネントを分け、後から機能を追加しやすい構成にする |
| 公開 | 日常利用のため、無料のホスティング（Vercel / GitHub Pages 等）で公開することを想定する |

## 6. 画面要件（概要）

画面は1つ（ボード画面）で、詳細はモーダルで表示する。

- **ボード画面**：リストが横に並び、各リスト内にカードが縦に並ぶ。末尾に「リストを追加」を置く。
- **カード詳細モーダル**（第2段階）：説明文、期限日、ラベルを編集する。

## 7. データ要件

```
Board
└─ List (id, title, order)
   └─ Card (id, title, description, dueDate, labelIds, order)
Label (id, name, color)
```

- 識別子（id）は一意な文字列とする。
- 並び順（order）で表示順を管理する。
- 保存形式は JSON とし、localStorage に保存する。

## 8. 制約・前提

- 開発環境は Windows 11、エディタは VSCode。
- サーバー・データベース・ログインは使わない。
- 【要確認】スクールの課題で、指定技術や提出期限、提出物の条件があるか。
- 【要確認】技術スタックは React + TypeScript + Vite + dnd-kit を想定している（確定前）。
